# 📊 Superstore Sales Analytics using Microsoft Excel

> A comprehensive Excel Analytics project developed using the Sample Superstore dataset to demonstrate advanced Excel functions, data cleaning, data analysis, Pivot Tables, dashboards, lookup formulas, logical functions, report automation, and VBA Macros.

---

## 📌 Project Overview

This project was completed as part of an **Advanced Excel Analytics Assignment** designed to strengthen practical Excel skills using a real-world retail dataset.

The project covers the complete Excel analytics workflow—from raw data exploration and cleaning to advanced analysis and dashboard creation. More than **12 modules** were implemented, including formulas, Pivot Tables, dashboards, report consolidation, conditional formatting, lookup functions, logical functions, and basic VBA Macros.

The final deliverable is an interactive Excel dashboard that enables users to analyze sales performance across regions, product categories, customer segments, and shipping methods.

# 📈 Business Insights

The analysis of the Superstore dataset revealed several important business insights:

- The **West** region generated the highest overall sales revenue.
- **Technology** products contributed significantly to revenue and profitability.
- The **Consumer** segment accounted for the largest share of profit.
- **Standard Class** was the most frequently used shipping mode.
- Monthly sales exhibited seasonal fluctuations, with stronger performance toward the end of the year.
- Certain high-discount orders resulted in reduced or negative profit, highlighting the impact of discount strategies on profitability.
- Delivery performance remained consistent, with an average delivery time of approximately four days.
